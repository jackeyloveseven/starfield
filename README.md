# 星空 · STARFIELD

一个单文件的纸上宇宙。用 Canvas2D 画的，没有任何库、没有外部资源，双击 `starfield.html` 就能跑。

深墨蓝的纸当底，星光是墨。一群折纸飞船沿着一条走廊飞，穿过五个区带（素纸 / 墨海 / 箔野 / 星核 / 深渊），
路上有行星、恒星、星云、星系印版，和一个真正的黑洞。

姊妹篇是 `migration.html`（候鸟 · MIGRATION）——同一个纸的世界，光反过来。

## 打开

直接双击 `starfield.html`。零依赖、零构建、无网络请求。

## 操作

| | |
|---|---|
| 移动光标 | 引导船队（引力会把它们带偏）|
| 点击 | 开始 / 暂停 |
| 空格 | 暂停 |
| 右下角按钮 | 自动运镜 / 图层 / 暂停 / 全屏 |

## 技术

- **纯 Canvas2D**，深度排序的渲染队列（多边形 / 描边 / 精灵 / 辉光 / 屏幕空间合成五种图元）
- **零依赖单文件**，约 4.7 MB，其中大部分是内嵌的 6 首原创配乐（base64 MP3，无外链）
- **程序化生成**：所有星、星云、行星、星系、黑洞都由种子确定性生成，`?seed=1a2b` 可复现
- **全帧后期**：对比度 / 饱和度曲线 + 辉光 + 暗角，黑点跟着区带的底色自适应
- **黑洞是真正的测地线光线追踪**：一块离屏 WebGL 精灵，逐像素积分史瓦西零测地线，
  记录最多三次赤道面穿越，所以吸积盘的多重像（直接像、上方透镜像、下方透镜像）是从积分里
  算出来的，不是画上去的。主画面仍然是 Canvas2D。

## 构建工具链

`tools/` 是建造过程中用到的补丁脚本和校验工具，不是运行时依赖。

- `v*.py` / `p*.py` — 按顺序跑的补丁脚本，每一个只跑一次
- `shot.py` / `holeshot.py` / `capsate.py` — 无头 Chrome 截图，探针是同步的
- `framecompare.py` — **整帧、1 倍**的新旧对比。这是唯一算数的验收口径
- `feel.py` / `captest.py` — 队形半径、捕获频率
- `crop.py` — 裁切放大，只用来定位 bug，不用来验收

`tools/BUILD-LOG.md` 记着每一版为什么改、量到了什么、以及踩过的坑。
