# 星空 · STARFIELD

一个单文件的纸上宇宙。Canvas2D 画的，零依赖、零外部资源、零网络请求，双击 `starfield.html` 就能跑。

深墨蓝的纸当底，星光是墨。一队折纸飞船沿着一条走廊飞，穿过五个区带（素纸 / 墨海 / 箔野 / 星核 / 深渊），
路上会遇到行星、红巨星、母舰、虫洞、超新星，以及一个逐像素积分出来的黑洞。

姊妹篇是 `migration.html`（候鸟 · MIGRATION）：同一个纸的世界，光反过来。

**在线**：https://jackeyloveseven.github.io/starfield/

## 打开

双击 `starfield.html`。要复现同一片天空，加种子：`starfield.html?seed=1a2b`。

## 手机端

同一份文件在手机上是一套**独立的触控界面**，不是把桌面工具栏缩小：

- **左下角隐形浮动摇杆**：静止时完全透明，按下才浮出圆心与旋钮，松手弹回原位并淡出。
- **右下角四键动作行**：`BOOST`（脉冲加速）/ `视角`（机位切换）/ `专注`（番茄钟）/ `更多`
  （图鉴、舱内、编队、调音、横竖屏）。展开的「更多」托盘在四键上方浮出。
- **布局按视口重排**：竖屏与 `≤600px` 走一套居中排版，`≤900px 或 pointer:coarse` 隐藏桌面
  工具栏与键盘提示；所有贴边元素都读 `env(safe-area-inset-*)`，刘海与小白条不会盖字。

三条在真机上踩出来的规则：

1. **`#comms-hud` 必须让开 `#camera-hud`。** 通讯卡是 `92vw` 居中、`top: pad+8`，而镜头名占
   `y 10..104 / x 14..172` —— 手机宽度下它会把镜头名整块盖住。窄屏/短屏下通讯卡统一压到
   `y 106`，并把卡片改成一行字的尺寸（`min(560px, 66vw)`，12.5px）。
2. **`.poem-line` 是 `nowrap`。** 桌面下靠 `right: 8%` 右对齐就够，竖屏 `max-width: 36%` = 140px
   时诗句会跑到屏幕外 160px。手机端放开换行并把上限提到 `66vw`。
3. **居中 flex 子项是 max-content 宽。** `.destinations` 在纵向 flex 里不会自动换行，最后一个
   起航点被右边缘切掉；显式 `width: 100%` 才会折行。

竖屏还要给触控行让位：`#journey` 的里程/时间行正好在 BOOST 行底下，手机上整体上移 58px。

## 独立游戏进阶系统

在保持纯单文件、零依赖（Vanilla JS + Canvas 2D + Web Audio）的纯粹架构下，星空引入了完整的独立游戏交互与探索闭环：

### 1. 深空图鉴与星际档案 (Celestial Codex)
按 `Tab` 或 `J` 唤出半透明磨砂星图档案。
- **天体档案 (Celestial Archive)**：卡冈图雅、米勒水星、二向箔坍缩域、创生之柱等深空天体实况观测记录。
- **奇观矩阵 (Cosmic Wonders)**：脉冲星灯塔、戴森环核心、旅行者金唱片、星灵水晶尖塔等 8 大隐秘奇观解构。
- **航行手记 (Voyage Chronicle)**：收纳 70+ 篇在漫长航程中偶得的哲学碎语与光年手记。
- **探索里程碑 (Milestones)**：包含超空间曲率巡航、引力弹弓掠夺者、深空常客等成就树，进度由 `localStorage` 本地原子持久化。

### 2. 4K 壁纸摄影工坊 (Deep Space Photo Studio)
按 `P` 键随时冻结时空，隐藏所有航行 HUD，进入电影级运镜定格：
- **艺术滤镜**：宣纸原画 (Papercraft)、深空水墨 (Ink Wash)、暮光金箔 (Golden Foil)、胶片颗粒 (Grain Film)、银盐黑白 (Monochrome Noir)。
- **电影级画幅导引**：支持 2.39:1 CinemaScope 变形宽银幕、16:9 经典画幅与全屏定格。
- **星历印记与一键导出**：自动压印航程光年、航区编码与种子哈希，点击 `[ 📷 导出高清壁纸 ]` 即可将当前视口渲染为无损 PNG 原图。

### 3. 动态舰队战术阵型 (Fleet Dynamic Formations)
按 `F` 或数字键 `1` ~ `4` 随时重组纸鹤护航舰队：
- `1` 楔形突防 (Delta V)：经典三角突进破风阵列。

- `3` 双环护航 (Orbital Ring)：内外同心逆向自转的保护性环阵。
- `4` 长蛇针列 (Tandem Needle)：贯穿引力走廊的狭长穿透阵列。
- 采用弹簧阻尼动力学（Spring-Damper Physics），在阵型切换时纸鹤们会优雅地在三维空间中划出平滑弧线。

### 4. 引力弹弓超载爆发 (Gravitational Slingshot Surge)
当编队以低轨极限掠过卡冈图雅黑洞或超大质量类地巨行星时，引力势阱将触发 **引力弹弓效应**：
- 画面展开多重环状重力冲击波与光子畸变。
- 航速瞬间激增 +50%，引擎喷流爆发金色光辉，伴随实时引力过载提示。

## 世界是怎么生成的

全部由种子确定性生成，没有随机贴图、没有预渲染序列。

### 走廊与区带
`routeX(z)` 是一条解析曲线，被 7 个子系统同时读取（编队、相机、天体、尘埃、发射源……）。
五个区带之间是宽 3,700 单位的**波纹状过渡带**，换区永远是渐变，不是切色。

### 天体的组合牌堆
每个遭遇从一副**280 张的牌**里抽一张，洗满 280 张才进入下一轮（每轮的洗牌顺序不同）：

```
4 形状（圆 / 带环 / 扁 / 碎裂）
× 7 类型（海 / 熔岩 / 林 / 城 / 冰 / 沙 / 气）
× 10 表现（掠水、母舰护航、星灵水晶、虫族菌毯、地球彩蛋、
          赛博巨构、沙丘、碎裂灾变、超级风暴、虚空）
```

再叠 **6 个尺寸档**与**每世界独立色调**（`shiftTone()`：暖/冷偏置 + 明度摆动），
所以同类型的两颗星在屏幕上也能一眼分开。

- 表现是逐种画的，不是换颜色：掠水有贴面低空的海面，母舰护航有编队，虫族是蠕动菌毯，地球是云带 + 海岸 + 夜面城市灯。
- 地球彩蛋约 1/16 概率覆盖任意一张牌。

### 其他事件
- **母舰**：长 900–2,000 世界单位的纸船体，三段轮廓 + 吃水线 + 舷窗 + 航行灯，每 5 个区块一艘
- **虫洞**：立在航道上的纸环，穿过时进入**格架喉道**（每层画自己的格 + 周围 8 格，时间被摆成一条走廊），出洞即换区
- **超新星**：远处的光，按画面边缘距离渐隐，不会只露半根辐条飘在角落
- **星系印版**：平涂板 + 硬边外缘 + 旋臂中心线，按屏幕半径门控
- **遭遇战**：每 37 个区块，航道两侧各五艘主力舰对射。舰体走现有的船队管线，
  炮火是细纸白的短线（脉冲开火 + 炮口辉光），中间夹着纸花一样的防空爆点；
  第一次进入视野时报一次「遭遇战 · SKIRMISH」

### 星云
不是天空贴图。每团星云在世界里有自己的中心和半径，按 `project()` 缩放、按深度入队，
所以行星会挡住它；从旁边掠过时它先变大再散开，而不是永远挂在同一片天上。

### 五维空间（彩蛋）
黑洞掠过的六十秒结束后，有 45% 的概率进入一间**纸房间**：三面墙按透视细分，
格子共享边、竖框向灭点收敛，机位在屋里缓慢浮动。每扇窗是纸白的光、一条地平线，
有时一颗墨色星球；进入时有半秒纸白闪光——换的是介质，不是叠一层。九秒后回到航道。
同一 seed、同一位置可复现。

### 黑洞
一块离屏 WebGL 精灵，逐像素积分**史瓦西零测地线**：`a = -1.5·h²·r̂ / r⁴`，kick-drift-kick、
自适应步长、最多 540 步，记录最多**三次赤道面穿越**。所以吸积盘的多重像（直接像 / 上方透镜像 /
下方透镜像）是从积分里算出来的，不是画上去的；光子环是一条细锐的平顶带。

盘的着色半径是阴影的 2.16 倍（`DISCOUT` 5.6 rs），这个比值是被机位反推出来的：
再宽一点，镜头贴近时就会钻进气体里，整屏死白。

接近时有一个**专用机位**：视线目标向洞偏转、按半径倍数保持距离，并用 `uExp` 把发光增益
随绘制尺寸与距离收缩——否则一颗占满画面的洞只会是一块白或一块黑。

### 驾驶舱
`V` 进入。机位坐在领队纸鹤后上方 640 单位——再近，编队就不是一群鸟而是一叠纸片了——
用编队自己的航向，呼吸起伏 ±1.9、转弯按航道曲率压坡度。
座舱罩在场景之后、印后处理之前画：两侧纸折板（带缝线）、顶部横梁、玻璃灰点、角落雾气，
底部一块**纸仪表台**——三块表（速 / 程 / 高，读的是真实模拟值）、罗盘带、一行「航程 N · 第 N 段」。

## 渲染

- **纯 Canvas2D**：深度排序队列，五种图元（多边形 / 描边 / 精灵 / 辉光 / 屏幕空间合成闭包）
- **Lambert 球面**：等亮度线是椭圆（`b = x·lx + y·ly + z·lz`），烘成 320² 精灵，
  每个天体一次 `drawImage` + 一次 `multiply` 上色——同心圆渐变是塑料感的唯一来源
- **全帧后期**：`contrast/brightness/saturate` 曲线 + 1/4 分辨率辉光 + 乘性暗角 + 纸纹颗粒
- **黑点跟着区带走**：固定斜率 A=1.40，黑点 `v0 = clamp(skyLum·0.62, 4, 30)`；
  固定黑点会把深渊（p50≈21）压成 71% 纯黑
- **单个 flush**：天体和舰队在同一个队列里排序，纸鹤在行星背面时不会被画到前面

## 性能

1600×900 下稳定 60 fps，`fillMPx ≈ 10`。DPR 上限 2；黑洞精灵按 `SPRITE_CAP = 2048` 封顶。
无头截图必须强制 SwiftShader（`--use-angle=swiftshader --enable-unsafe-swiftshader`），
否则重 WebGL 会打崩 NVIDIA 驱动。

## 热更新（APK）

Android 版是 WebView 壳：`MainActivity` 开机先加载 `filesDir/starfield_active.html`（上次热更新的
产物），没有就加载 APK 里打包的那份；随后后台拉 `version.json`，`build` 比本地大就下载整页 HTML，
校验后原子替换，再通过 JS 桥告诉页面「有新版本」。

这条链路上原先有五个会让它**静默失败**的地方，全部已修：

| 问题 | 后果 |
|---|---|
| 页面只处理 `OTA_READY`，`OTA_ERROR` 无人接 | 手动点「检查更新」→ 一句「正在查询…」→ 永远没有下文，看起来就是「总是失败」 |
| 原生把版本号当**字符串**发，页面读 `payload.version` | 弹窗永远显示写死的 `v1.1.0`，即使更新成功也像没更新 |
| 设置面板调 `getBuildNumber()`，桥上没有这个方法 | 那一行抛异常，版本号永远停在硬编码值 |
| 完整性门槛 `> 500 KB`，而整页 ~21 MB | 断网续传拿到半页也能通过校验 → 装进去就是白屏 |
| 热更新文件落在 `filesDir`，但 `./libs/` 不在那里 | 更新后 `three.min.js` 404，退回 CDN；离线启动则没有 THREE |

现在的做法：`connect 15s / read 45s`；比对 `Content-Length` + 下限 4 MB + 尾部必须是 `</html>`；
`renameTo` 失败则退回复制；`onPageFinished` 之前到达的通知先挂起再补发；启动时把 `libs/`、图标、
`manifest.json` 从 assets 镜像到 `filesDir`，让热更新页能解析相对路径；手动检查若无新版本会明确
回一句「已是最新版本」。

**注意**：热更新只能换 HTML，换不了 `MainActivity.java`。原生侧的修复必须发一次新 APK
（`android/**` 有改动时 `build-apk.yml` 会自动构建并更新 Release），装过一次之后再往后才走 OTA。

## 构建工具链

`tools/` 是建造过程中的补丁脚本与探针，**不是运行时依赖**。

- `v*.py` — 按顺序跑的补丁脚本，每个只跑一次，每个替换都断言「出现次数 == 1」
- `shot.py` / `holeshot.py` / `encshot.py` — 无头 Chrome 截图（探针同步）
- `framecompare.py` — **整帧、1 倍**的新旧对比；唯一算数的验收口径。放大图只能用来定位 bug
- `feel.py` / `captest.py` — 队形半径、捕获频率与可达性

`tools/BUILD-LOG.md` 记着每一版为什么改、量到了什么、踩过什么坑。
